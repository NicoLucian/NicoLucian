## What I'm building

### [authwatch](https://github.com/NicoLucian/authwatch) — Linux auth log triage
A dependency-free Python tool that parses `auth.log`, `secure` or `journalctl` exports and ranks brute-force, password-spraying and suspicious-login findings by severity, each one mapped to **MITRE ATT&CK** and **NIST CSF**. The output is a console summary or a Markdown incident report you can paste into a ticket.

The point is not the code, it's the judgement: *is this noise, or is this an incident?*
